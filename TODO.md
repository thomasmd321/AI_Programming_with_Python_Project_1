## Done

### Tooling

- [x] The README said Python 3.7+, but the test tools need 3.10+ (and 3.9 is
      end-of-life). The README now says 3.10+, and CI tests 3.10, 3.12 and 3.13.
- [x] Dependabot opens weekly pull requests for newer pip packages and
      GitHub Actions (`.github/dependabot.yml`).

### Features

- [x] Model size and speed: every run prints the parameter count and the
      classification time per image, and the comparison table shows them
      beside the accuracy, with each run's total runtime. (The replayed
      outputs show "n/a" for seconds per image until the Colab run.)
- [x] Images are classified in batches of 16 (`classifier.predict_batch`).
      Same answers as one at a time; on a 4-core CPU 1.1–1.5× faster for most
      models (VGG about 10% slower), and usually more on a GPU.
- [x] Charts (`plot_results.py`, used by the Colab notebook): accuracy by
      model, speed against breed accuracy, and a grid of each model's
      mistakes with its top guesses.

- [x] `--topk N` prints the model's top N guesses, with confidence, for images
      whose labels don't match.
- [x] `--csv PATH` saves one row per image: labels, dog flags, confidence and
      top guesses (`export_results.py`).
- [x] Added ResNet-50 and EfficientNet-B0 (`--arch resnet50|efficientnet`).
      The batch scripts run every model, and the comparison table includes
      whichever models have output files.
- [x] A GPU is used automatically when one is available.
- [x] `notebooks/run_on_colab.ipynb` runs everything for real on Google Colab.

### Data

- [x] `German_Shepherd_02.jpg` and `Labradoodle_02.jpg` had the same pixels as
      the `_01` images, plus an EXIF "rotate 180°" tag. Image viewers honour
      that tag, but the classifier ignored it, so the models saw the same image
      twice. They are now true horizontal mirrors of `_01`, and `classifier.py`
      applies EXIF orientation (no other image has a rotation tag).
- [x] Added `labradoodle` to `dognames.txt`, so labradoodle photos count as
      dogs. Not-a-dog accuracy on `uploaded_images/` went from 60% to 100% for
      every model.

### Bugs

- [x] `calculates_results_stats.py`: `n_correct_notdogs` counted every
      non-dog image as correct. It now also requires the classifier to say
      "not a dog". This changed ResNet's not-a-dog score on `pet_images/` from
      100% to 90%. The printed statistics now agree with Udacity's own check in
      every saved output file; before, 4 of the 6 disagreed.
- [x] `get_pet_labels.py`: a `for ... else` printed a false "already exists"
      warning on every run. Removed.
- [x] `calculates_results_stats.py`: breed accuracy used a substring test
      instead of the match flag. It now requires a match and both dog flags,
      the same rule as Udacity's check.
- [x] `classify_images.py`: labels matched as raw substrings (`"cat"` matched
      `"polecat"`). Now matches whole words (`labels_match`).
- [x] `adjust_results4_isadog.py`: the first line of the dog file was never
      split on commas. Every line is now loaded the same way.
- [x] `print_model_tables.py`: parsing relied on line order and list
      positions. It now reads each statistic by name, only from the results
      section.

### Robustness

- [x] Image paths are built with `os.path.join`, so `--dir` works with or
      without a trailing slash.
- [x] `get_pet_labels` skips hidden and non-image files and sorts filenames.
      It also strips the extension first, so `cat.jpg` gives the label `cat`.
- [x] `--arch` is limited to `resnet`, `alexnet` and `vgg`.
- [x] `classifier.py` finds `imagenet1000_clsid_to_human.txt` next to itself
      and rejects unknown model names. It also converts images to RGB.
- [x] `print_model_tables.py` takes the image counts from the first file
      instead of hard-coding `alexnet`.

### Maintainability and style

- [x] `adjust_results4_isadog` loads dog names into a `set` in one loop and no
      longer prints "Key is already in" for every duplicate.
- [x] `get_pet_labels` simplified to `label_from_filename`.
- [x] Percentages use a `pct(part, whole)` helper instead of
      try/except blocks and debug prints.
- [x] Runtime prints as `h:mm:ss` (`0:00:32`).
- [x] `print_results` shows readable names (`% Correct Dogs`).
      `print_model_tables.py` reads the same names from `print_results.py`.
- [x] `print_model_tables.py` has a `main()`. `check_images.py` no longer
      prints the cross-model tables, because during a batch run it read output
      files that were still being written. The batch scripts print the table
      after all three runs.
- [x] Warnings go through `logging` (to stderr), not `print`.
- [x] Full flake8 runs in CI (settings in `setup.cfg`), including the
      Udacity-supplied files after whitespace fixes.
